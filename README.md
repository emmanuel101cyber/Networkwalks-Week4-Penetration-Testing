**Batch:** B083

**Duration:** 5 Days

## Project Overview

This repository documents my Week 4 penetration testing project under the Networkwalks Cybersecurity Internship.

The engagement focuses on assessing the security posture of a web application through reconnaissance, vulnerability assessment, controlled security testing and professional reporting.

All testing activities are subject to the engagement's written authorisation and agreed scope.

## Project Objectives

- Conduct domain and DNS reconnaissance.
- Identify publicly exposed technologies and services.
- Assess web application security.
- Investigate potential security weaknesses.
- Document verified findings and their security implications.
- Develop remediation recommendations.
- Produce a professional penetration testing report.

## Methodology

The assessment follows a structured penetration testing approach:

1. Reconnaissance
2. Attack Surface Assessment
3. Vulnerability Assessment
4. Controlled Validation
5. Evidence Collection
6. Reporting and Remediation
